# Manual verification checklist

요구사항의 28개 수동 시나리오는 README의 기본 QA를 먼저 수행한 뒤 아래 순서로 확장합니다.

- 창: 최초 실행, 8방향 리사이즈, 헤더 이동, 세 노트 생성, 종료/복원
- 콘텐츠: Unicode/여러 줄 붙여넣기, 스크린샷 붙여넣기, 이미지·텍스트·PDF·ZIP 드롭
- 이미지: 선택, 드래그 이동, 모서리 비율 리사이즈, inline 캡션 입력과 복원, 각 동작 undo/redo, 손상 파일 오류 처리
- 첨부: 더블클릭 열기, 파일 이동/삭제 후 경고
- Ink: 여러 stroke, 펜/지우개 전환, 7개 색상과 5개 굵기, scribble 삭제와 단일 undo 복원, 일반 직선 오탐 여부
- 통합: 전역 단축키 등록/충돌, 시작프로그램 등록/해제, 트레이 표시/숨김/종료, 보조 모니터 재실행, 모니터 제거 후 재실행, DPI 100/125/150/200%

현재 README의 제한사항에 열거된 시나리오는 구현 완료 후 회귀 항목으로 전환해야 합니다.
